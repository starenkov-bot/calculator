КАЛЬКУЛЯТОР (PYTHON 3)
======================

Консольная программа-калькулятор на языке Python 3 для выполнения базовых арифметических операций.

ВОЗМОЖНОСТИ ПРОГРАММЫ
---------------------
- Сложение (+)
- Вычитание (-)
- Умножение (*)
- Деление (/)
- Возведение в степень (**)
- Обработка некорректного ввода (защита от ввода букв и пустых строк)
- Обработка ошибки деления на ноль

СИСТЕМНЫЕ ТРЕБОВАНИЯ
--------------------
- Python версии 3.10 или выше
- ОС РЕД ОС (или любой другой дистрибутив Linux / Windows)

УСТАНОВКА И ЗАПУСК
------------------
1. Клонируйте репозиторий на локальный компьютер:
   git clone https://github.com/starenkov-bot/calculator.git
   cd calculator

2. Создайте виртуальное окружение:
   python3 -m venv venv

3. Активируйте виртуальное окружение:
   - Для Linux / РЕД ОС: source venv/bin/activate
   - Для Windows: venv\Scripts\activate

4. Запустите программу:
   python main.py

СТРУКТУРА ПРОЕКТА
-----------------
- main.py    — основной исполняемый файл с логикой калькулятора
- .gitignore — список игнорируемых служебных файлов и папок (venv, __pycache__)
- README.txt — описание проекта и инструкция по запуску
